# Spotify-History-Analysis
📌 Project Overview

This project presents a comprehensive Spotify Listening History Analytics Dashboard that analyzes user music consumption behavior using Power BI. The dashboard focuses on understanding user engagement, listening patterns, skip behavior, and platform usage.

The objective of this project is to transform raw streaming data into actionable insights that can help improve recommendation systems, user retention strategies, and personalized music experiences.

This project reflects real-world applications of data analytics in digital streaming platforms, making it highly relevant for roles in Data Analytics, Product Analytics, and Business Intelligence.

📁 Dataset

The dataset used in this project is based on Spotify listening history and includes:

✔ Track-level listening data (plays, skips, engagement)
✔ Artist information
✔ Timestamp data (hour, weekday, monthly trends)
✔ Platform usage (Android, iOS, Web, etc.)
✔ User interaction metrics (skip rate, full listen rate)

The dataset is structured to support behavioral analytics, time-series analysis, and user segmentation.

🛠 Tools & Technologies

Purpose-wise tools used in the project:

Data Visualization: Power BI
Data Processing: Power Query Editor
Data Modeling: DAX (Data Analysis Expressions)
🧠 Workflow / Steps
🔹 Data Loading
Imported Spotify history dataset into Power BI
Verified schema and data types
Applied filters for year-wise analysis (2013–2024)
🔹 Data Transformation
Cleaned and formatted timestamps (hour, weekday, month)
Created calculated columns such as:
Skip Rate
Full Listen Rate
Engagement Metrics
🔹 Data Modeling
Built relationships between listening data and metadata
Created DAX measures for KPIs such as:
Total Plays
Total Listening Hours
Skip Rate
Engagement Score
🔹 Dashboard Development

The dashboard is designed with a Spotify-themed UI (black, green, white) and includes:

✔ KPI cards for quick insights
✔ Time-based listening trends
✔ Artist and platform analysis
✔ Skip behavior visualization
✔ Interactive filters (year selection)
